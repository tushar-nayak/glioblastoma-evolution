What Is Working

The repository contains two runnable analysis pipelines plus the static site itself. Both scripts compile cleanly, import the declared core dependencies, and expose command-line entry points.

Neural ODE pipeline

scripts/run_neural_ode_pipeline.py implements the history-conditioned model, dataset loading, training loop, evaluation helpers, and figure generation for local patient folders.

Physics-informed pipeline

scripts/run_physics_pipeline.py provides the 3D physics-informed comparison branch with its own training, evaluation, and reporting path.
